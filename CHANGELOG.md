# Cairn release notes

## 0.1.0 — initial MVP

- Introduced the Cairn invitation-access product and alpine visual identity.
- Added explicit private witnesses and clearance-bound invitation commitments.
- Added replay, badge-uniqueness and capacity invariants.
- Built browser deployment, admin policy/rotation controls and a wallet-free registry.
- Separated transaction submission from indexed confirmation.
- Added persistent day/night mode, responsive layouts and accessibility checks.
- Added generated-contract tests, application utility tests and CI verification.

Deployment, hosted repository history and launch evidence are recorded separately in the submission checklist once they exist.
