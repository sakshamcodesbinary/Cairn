# Contributing to Cairn

Keep the product narrow: private invitation access with an honest public record.

1. Use Node 22 and the documented Compact compiler.
2. Install root and frontend dependencies with `npm ci`.
3. Change source, not generated artifacts. Regenerate with `npm run compile` when the contract changes.
4. Run `npm run check`, `npm test`, `npm run test:app`, `npm run build` and the frontend browser tests.
5. Explain privacy-impacting changes in both the contract specification and README.
6. Verify day/night modes, keyboard navigation, small screens, honest loading/errors and network separation.

Never include real invitation/admin/wallet secrets, unencrypted backups, local databases or falsely claimed deployment evidence. Avoid broad dependency upgrades that change the ledger/compiler ABI without regenerating and retesting the complete stack.

The owner will initialize the repository and maintain meaningful change history. No artificial commit count is generated by this project.
