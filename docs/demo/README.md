# Cairn demo recording plan

Record actual application behavior on Preprod. No old or fabricated deployment recording is included.

Suggested one-minute edit:

1. 0–10 seconds: overview, day/night switch and explanation of the invitation product.
2. 10–20 seconds: show the active Preprod address and connect Lace.
3. 20–40 seconds: submit a real issued invitation, show wallet approval and indexed confirmation. Cut waiting time honestly; do not replace it with simulated success.
4. 40–50 seconds: inspect the public registry and look up the receipt’s badge.
5. 50–60 seconds: show the admin policy controls and explain which witness values were not published. Disconnect.

Keep the wallet’s recovery phrase, administrator secret, maintenance key and unencrypted backup out of every frame. Inputs are masked but clipboard tools/download previews can still leak them. Include the live demo, Preprod address, product profile and repository in the final submission only once they exist.
